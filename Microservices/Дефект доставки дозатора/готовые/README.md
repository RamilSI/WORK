## Как найдена трещина

1. **Детектор тёмных тонких структур** (black-hat, структурный элемент 9×9) по светлым участкам пластика: трещина и щель — это тёмная линия на светлом фоне.
2. Порог — 99,5-й перцентиль отклика на светлых участках; связные компоненты фильтруются по площади, вытянутости и плотности.
3. Кластер кандидатов сошёлся в одну вертикальную линию у правого края крышки: x ≈ 2842…2865, y ≈ 1816…2317 (в пикселях оригинала).
4. Проверка цветом: в зоне фокуса Y≈111, U≈115, V≈134 — нейтральный светлый пластик. Прежний (ошибочный) центр кадра давал Y≈175, U≈91, V≈157 — это дерево обрешётки.
